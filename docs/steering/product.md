# Product — todayfin

## 비전

시장 판단에 필요한 핵심 지표 확인 루틴(유튜브 "알상무"의 데일리 체크리스트)을 자동화한다. 매일 아침·저녁, 한 페이지에서 수급→가격→거시→원자재를 순서대로 훑고 상세 차트로 파고들 수 있게 한다.

## 타깃

- **1차 (MVP)**: 운영자 본인 — 개인 투자자, 폰/PC 어디서나 URL로 접속
- **2차 (게이트 통과 후)**: 같은 지표 루틴을 따르는 일반 개인 투자자 — 대중 공유는 `docs/data-rights.md`의 데이터 권리 게이트 통과가 선행 조건

## 핵심 가치 (우선순위 순)

1. **데이터 정확성** — canonical 지표 정의 고정, 동일-정의 소스만 폴백, 검증 실패 시 기존 데이터 유지(stale 표시)
2. **보기 쉽고 자세한 시각화** — 홈 한눈 조망(카드+미니차트) → 상세 분석(캔들·이동평균·기간 선택)
3. **사용자 친화·심미** — Ollama 스타일 미니멀 디자인, 모바일 최적화

## 지표 구성 (알상무 분류)

① 수급: 외국인 순매수(코스피, 4주MA)·주체별 순매수(코스피/코스닥)
② 시장 가격·추세: 코스피·코스닥·삼성전자·SK하이닉스 (이동평균 20/60/120일)
③ 거시·통화: 원/달러·달러/엔·미국채 10년·국고채 3년
④ 원자재: WTI 최근월 선물 (60일 MA)

## 제약

- 비용 0원: 무료 데이터 소스 + GitHub Actions/Pages 무료 티어만 사용
- 갱신은 기본적으로 일봉 기준 하루 2회(장전/장후). 단 2026-08-03부터 수급 2종·코스피 등 4종·환율/WTI 3종(총 9종)은 정규장 중 30분 간격 준실시간 갱신 추가(`docs/specs/near-realtime-updates/`) — 국채 4종은 하루 1회 고시값 성격이라 대상 제외. 완전 실시간(초 단위 틱)은 여전히 비목표
- 2단계 로드맵: 기준일 선택 누적수익률 비교(롱숏), ECOS 매매기준율, 수급 세부 주체, 알림
