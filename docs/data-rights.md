# 데이터 소스 권리·공개 수위 — todayfin

목적: 소스별 이용 조건과 재배포 리스크를 기록하고, 사이트 공개 수위를 결정한다.
원칙: **면책 문구·출처 표기는 이용 허가를 대체하지 않는다.** public repo에 커밋한 데이터는 fork·clone에 잔존한다.

## 공개 수위 결정 (2026-08-03)

- **MVP**: GitHub Pages URL로 배포하되 **홍보·공유하지 않는 개인 운영** (검색 유입 최소화: robots 차단은 하지 않되 홍보 금지)
- **대중 공유 게이트**: 아래 매트릭스의 미확인 항목을 해소하고, 필요 시 소스 제공자에게 서면 확인을 받은 뒤에만 공유 — 게이트 통과 전 SNS·커뮤니티 공유 금지

## 리스크 완화

1. 사이트는 **차트 표시용 가공 데이터**만 배포 (호가·틱 등 원본 덤프 아님, 일봉 요약 수준)
2. 모든 페이지에 출처 표기 + 면책 문구
3. 지표당 5년 일봉으로 범위 제한 (전 종목 덤프 같은 대량 재배포 아님)
4. 대중 공유 결정 시: KRX(공식 API 허용 범위)·Stooq(재배포 조건) 우선 확인, 불가 판정 소스는 해당 지표 비노출 또는 대체
