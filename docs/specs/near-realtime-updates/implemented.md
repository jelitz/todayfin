# Implemented — near-realtime-updates

## 설계 편차·실측으로 확인된 사항

| 항목 | 내용 |
|------|------|
| WTI가 market_hours 실행 직후에도 "장중" 배지가 안 뜬 것 | 버그 아님. yfinance의 `CL=F`(WTI 선물) 일봉이 월요일 세션 시작 시점에는 아직 오늘 날짜로 집계되지 않고 전주 일요일 세션 날짜(`2026-08-02`)에 머물러 있음(실측 확인 — `yf.download('CL=F', period='7d', interval='1d')`로 원본 응답 자체가 그러함, 거래량도 낮아 형성 중인 세션임을 시사). `isIntraday()`는 `observed_last === 오늘`만 참으로 판정하므로 이 경우 정확히 "장중 아님"으로 처리됨 — 데이터 정확성 우선 원칙이 의도대로 동작한 사례. 코드 수정 불필요, 다음 회차 이후 yfinance가 오늘 날짜를 발행하면 자동 해소됨. |
| `collect_one()` 시그니처에 `profile` 파라미터 추가 | 기존에는 프로필 정보가 필요 없었으나, market_hours 분기 판단에 필요해 추가(기본값 `"all"`로 기존 호출부 호환 유지 — 실제로는 `main()`에서 항상 명시적으로 전달) |
| `App.tsx` 폴링 실패 처리에서 stale-closure 버그를 구현 중 직접 발견·수정 | 최초 구현에서 `catch` 블록이 `summary` state를 직접 참조했는데, `useEffect` 의존성 배열이 `[]`라 이 클로저는 마운트 시점의 `summary`(항상 `null`)만 영원히 참조함 — 최초 로드 성공 후 나중에 폴링이 실패하면 `summary`가 실제로는 값이 있는데도 "없음"으로 오판해 정상 표시 중인 데이터를 에러 화면으로 덮어쓸 뻔했음. 코드 리뷰 단계에서 발견해 `useRef`(`hasLoadedRef`)로 전환해 수정 — 실행 없이 정적으로 코드를 다시 읽다가 발견한 유형(런타임 버그를 코드 리뷰로 잡은 사례). |

## 브라우저 검증 결과

로컬 dev 서버에 실제 `market_hours` 프로필 수집 결과를 반영해 확인:
- 대상 9개 지표 중 8개(WTI 제외, 위 사유)가 카드·티커 양쪽에 정확히 "장중" 배지 표시(DOM 조회로 16/24 티커 항목 = 8개 지표 × 2배 복제 확인)
- 국채 4종·전일 이전 데이터에는 배지 미표시 확인
- 라이트/다크 모두 배지 가독성 확인(다크에서 accent 톤 정상 대비)
- 프론트 폴링(5분 간격)은 코드 리뷰 + 타입체크로 검증(실제 5분 대기는 세션 내 비효율적이라 생략 — 스테일 클로저 버그를 리뷰로 미리 잡았으므로 로직 신뢰도는 높음)

## 배포 후 사용자 리포트로 발견·수정한 버그 (2026-08-03, 배포 직후)

**티커 바·카드가 예전 데이터를 계속 보여줌**: 실제 원인은 두 겹의 캐시였음.
1. `App.tsx`/`Detail.tsx`의 `fetch()`가 쿼리스트링·캐시 옵션 없이 고정 URL(`data/summary.json` 등)을 호출해, 브라우저·GitHub Pages CDN이 이전 응답을 그대로 재사용 — 백엔드(30분 크론)는 정상 갱신되는데 프론트가 5분마다 "같은 캐시"만 다시 읽고 있었음. 쿼리 타임스탬프(`?_=${Date.now()}`) + `cache: 'no-store'`로 매 요청을 캐시 미스로 강제해 해결.
2. `index.html` 자체도 `Cache-Control: max-age=600`(10분)이 걸려 있어, 수정 커밋을 배포한 직후 기존에 페이지를 열어둔 브라우저는 최대 10분간 **구 버전 JS 번들**을 계속 실행할 수 있음(내용 자체는 정상 배포됐으나 클라이언트가 아직 못 받아온 상태) — 이건 GitHub Pages의 정상적인 정적 사이트 캐싱 정책이라 별도 조치 없음(신규 방문자·10분 경과 후 재방문자는 자동 해소).

검증: 배포 직후 새 탭에서 캐시 우회 없이 접속 시 구 번들(`index-B_Rugb1C.js`)이 여전히 로드됨을 확인(2번 원인) → 쿼리 파라미터로 강제 재요청하니 새 번들(`index-Do9sGwcj.js`)과 최신 데이터(코스피 6,291.13, 2026-08-03, "장중" 배지 정상 표시)가 정상 반영됨을 확인.
