# Requirements — global-indicators

해외 지수·환율·원자재 지표 7종 추가: 나스닥, S&P 500, 다우존스, 니케이 225, 유로/달러, 달러인덱스, 금 선물 (2026-08-08 사용자 요청).

## 배경과 목적

홈 지표가 국내 중심(코스피·코스닥·개별주·원/달러·달러/엔·국채·WTI·VKOSPI)이라 글로벌 시장 맥락(미국·일본 증시, 달러 강세, 금)이 빠져 있다. "빠르게 현재 주요 지표를 파악한다"는 홈의 목적에 맞춰 글로벌 핵심 지표를 같은 테이블 문법으로 추가한다.

인터뷰 결정(2026-08-08):

- 골드는 **국제 금 선물**(COMEX 최근월, 달러/온스) — KRX 금현물(원/g)은 환율 효과가 섞여 제외
- 해외 지수 4종은 **"시장 가격·추세" 섹션 내 국내/해외 소그룹**으로 배치(새 섹션 아님)

기존 `yfinance_source` 어댑터 경로. 7종 전 심볼 로컬 프로브에서 최근 10일 + 5년 이력(1,223~1,300행) 정상 수신:

- **폴백 없음**: 기존 yfinance 지표 3종과 동일 정책. 실패 시 stale 유지, 3영업일 초과 시 워크플로우 실패 승격(기존 규칙).

## 요구사항

- R1. WHEN 수집이 실행되면 THEN 시스템은 위 표의 7종을 각 타입에 맞는 `data/{id}.json`으로 저장해야 한다. 해외 지수 4종은 코스피·코스닥과 동일한 ohlcv(`[date, open, high, low, close, volume]`)로 저장한다 — 상세 화면에서 캔들 차트로 일관되게 보이기 위함. 현재 `yfinance_source`는 line(Close만) 전용이므로 ohlcv 반환을 확장한다.
- R2. 수집 프로필: 미국 지수 3종·유로/달러·달러인덱스·금은 **preopen**(한국 아침에 전일·당일 확정치 확보), 니케이는 **afterclose**(도쿄증권거래소 마감 15:30 JST=KST — 2024-11 연장 반영 — 이라 당일 종가를 저녁 수집에서 확보). market_hours(장중 30분 간격)에는 한국 장중에 실제로 움직이는 니케이·유로/달러·달러인덱스·금만 참여시키고, 한국 장중에 휴장인 미국 지수 3종은 제외한다.
- R3. 홈 테이블 재편: "시장 가격·추세" 섹션을 소그룹 **국내**(코스피·코스닥·삼성전자·SK하이닉스) / **해외**(나스닥·S&P 500·다우존스·니케이 225)로 나눈다. "거시·통화"의 환율 소그룹은 **"환율·달러인덱스"**로 제목을 바꾸고 유로/달러·달러인덱스를 추가한다(원/달러·달러/엔·유로/달러·달러인덱스 순). "원자재"에 금 선물을 추가한다(WTI·금 순).
- R4. 값 포맷: 유로/달러는 소수 4자리(2자리면 1.16으로 뭉개짐), 금 선물은 `4,401.30 USD/oz` 형태(WTI의 USD/bbl 패턴), 지수는 기존 pt 포맷(소수 2자리)을 따른다.
- R5. 상세 화면: 해외 지수 4종은 캔들 차트(거래량 서브패널은 기존 규칙대로 삼성전자·SK하이닉스만 유지), 유로/달러·달러인덱스·금은 기존 line 렌더를 그대로 사용한다.
- R6. 백필: 기존 자동 백필(파일 부재 시 5년) 메커니즘으로 첫 수집에서 확보한다.
- R7. 티커 바에 7종이 포함되어야 한다(summary 기반 자동 포함).
- R8. 소개 페이지 지표 목록에 7종 항목을 추가한다 — 각각 왜 보는가 한 줄(예: 달러인덱스=달러 강세→외국인 수급·환율 압력, 니케이=엔캐리·아시아 리스크 선행).

## 검증 계획

- pytest: yfinance ohlcv 변환(컬럼 매핑·중복 날짜 제거), 심볼 매핑, line 지표 기존 회귀
- vitest: SECTIONS 재편 반영(소그룹 헤더·순서), 신규 unit 포맷(USD 4자리·USD/oz)
- Actions 실행 1회에서 7종 `data/*.json` 생성 + summary 반영 확인, 배포 사이트에서 홈 테이블·티커·상세 확인(라이트/다크)

## 범위 제외 (백로그)

- KRX 금현물(원/g) 지표 — 인터뷰에서 국제 금 선물 단독으로 결정
- 미국 지수 선물(장중 갱신용 ES=F 등) — 정규장 확정치만 추적
- 항셍·상해종합 등 추가 아시아 지수
