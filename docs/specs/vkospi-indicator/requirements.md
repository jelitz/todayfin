# Requirements — vkospi-indicator

일간 VaR 추적 지표: 코스피200 변동성지수(VKOSPI)를 수집해 홈 새 섹션 "변동성·리스크"에 노출한다.

## 배경과 목적

메르 블로그 ["외국인들이 국장을 던지는 비밀 1"](https://blog.naver.com/ranto28/224371367594)의 논지: 외국계 기관(연기금 등)은 VaR 한도(위험예산)로 움직이므로, 담을 수 있는 코스피 최대 금액 = 위험예산 ÷ (일간변동성 × 신뢰수준계수). 변동성이 커지면 보유 한도가 기계적으로 줄어 외국인 매도가 나온다. 블로그가 추적 지표로 지목한 것이 VKOSPI(연율 표시, ÷16 ≈ 일간변동성)다. 이 지표로 "외국인이 코스피에 투자할 수 있는 자금의 변화"를 추적한다(2026-08-08 사용자 요청).

인터뷰 결정(2026-08-08):

- 표시는 **VKOSPI 원값만** — 투자여력 환산 그래프·실현변동성 파생 지표는 범위 제외(백로그)
- 홈에 다섯 번째 섹션 **"변동성·리스크"** 신설, 그 안에 배치

## 데이터 소스 (실측 완료)

- KRX Open API `idx/drvprod_dd_trd`(파생상품지수 시세), `IDX_NM` = "코스피 200 변동성지수"(`IDX_CLSS` 옵션지수)
- **활용신청 승인·Actions 러너 동작 실측 완료**: spike run 31209393183(2026-08-08), 2026-08-06 종가 77.17 수신 — 블로그의 "8월초 75~77선"과 교차 일치
- 필드: `BAS_DD`, `CLSPRC_IDX`(종가), `CMPPREVDD_IDX`, `FLUC_RT`, `OPNPRC_IDX`/`HGPRC_IDX`/`LWPRC_IDX` — 거래량 없음(`kospi_dd_trd`와 달리 `ACC_TRDVOL` 부재)
- 공표 시점: **T+1 영업일**(kospi_dd_trd와 동일 — 2026-08-08 실측에서 8/7 데이터 미공표 확인). afterclose 프로필이면 "전 영업일 데이터가 최신"이 정상 상태다.
- **동일 정의 폴백 없음**: yfinance·FinanceDataReader·네이버 금융·pykrx·CNBC 모두 VKOSPI 미제공/차단을 실측(2026-08-08). 실패 시 stale 유지.
- 실현변동성(과거 수익률 계산)은 내재변동성과 정의가 달라 폴백 금지 대상(아키텍처 제약 #2).

## 요구사항

- R1. WHEN afterclose 수집이 실행되면 THEN 시스템은 `drvprod_dd_trd` 응답에서 VKOSPI 행을 찾아(IDX_NM 공백 제거 후 "코스피200변동성지수" 매칭 — 표기 변형 방어) 종가를 `data/vkospi.json`(type `line`, `[date, value]`)으로 저장해야 한다. 스테이징→원자적 교체·최근 7일 lookback 병합은 기존 규칙을 따른다. 날짜는 ISO 정규화(`basDd` 원문 저장 금지 — kospi 때 버그 재발 방지).
- R2. WHEN 수집이 실패하거나 해당일 데이터가 미공표면 THEN 기존 데이터를 유지해야 하며(stale), 마지막 관측일이 3영업일 초과 지연되면 워크플로우 실패로 승격한다(기존 규칙 동일).
- R3. 홈에 다섯 번째 섹션 "변동성·리스크"가 추가되고 VKOSPI가 그 안에 노출되어야 한다. 등락 표기는 사이트 전역 규칙(+빨강/-파랑)을 따른다 — VKOSPI 상승은 "공포 확대"지만 색 의미 체계는 전역 일관성이 우선.
- R4. 상세 화면은 기존 line 지표 렌더(단색 선·테마 추종·MA 없음)를 그대로 사용해야 한다(코드 변경 없이 동작 — 2026-08-08 저장소 조사로 확인).
- R5. 소개 페이지 지표 목록에 VKOSPI 항목이 추가되어야 한다 — 왜 보는가(VaR 한도 메커니즘을 자체 문구로 요약) + 참고 출처 링크.
- R6. 백필: 최초 1회 로컬 백필로 기존 kospi와 같은 기간(약 5년, 2021-08~)을 확보한다. 단일 날짜 API라 영업일당 1회 호출(약 1,240회) — 호출 간 스로틀을 두고, 호출량 제한에 걸리면 확보 가능한 범위로 축소한다(제한 정책 미공개).
- R7. 티커 바에 VKOSPI가 포함되어야 한다(전 지표 요약이 summary.json 기반이므로 등록만으로 자동 포함 예상).

## 검증 계획

- pytest: 응답 파싱(IDX_NM 매칭·공백 변형·빈 응답·미공표일 처리), 날짜 ISO 정규화
- Actions 실행 1회에서 `data/vkospi.json` 생성 + `status: ok` 확인
- 홈·상세·티커 브라우저 확인(라이트/다크)

## 범위 제외 (백로그)

- 투자여력 환산 그래프("위험예산 100억원당 담을 수 있는 코스피 금액" = 예산 ÷ (일간변동성 × 1.645)) — 인터뷰에서 원값만으로 결정. 도입 시 95% 신뢰수준·1일 호라이즌 등 가정 각주 필수.
- 실현변동성(EWMA λ=0.94, RiskMetrics) 별도 지표 — kospi 이력 1,220여 일로 산출 가능함은 확인됨
- cVaR 등 후속 지표(블로그 2편 예고 범위)
