# Requirements — news-headlines (한국어 금융 뉴스 헤드라인 5줄)

2026-08-08 사용자 요청: "financial 뉴스의 주요 헤드라인만 5줄로 현재 페이지에 지표와 상단의
소개 메시지 사이에 뜨도록. 반드시 한국어. 핵심적인 주요뉴스 헤드라인이어야 해." (참고 예시:
시각 + 출처 아이콘 + 제목 링크 형태의 Headlines 박스)

> 2026-08-08 개정: 수집 상한은 news-page 스펙(docs/specs/news-page/)으로 5→70건 확대.
> 홈 표시는 여전히 5건 — 이 문서의 "5건" 서술은 홈 표시 기준으로만 유효.

인터뷰 확정(2026-08-08): 소스 = **Google News 비즈니스 헤드라인**(한국판), 갱신 = **매시간**
(유튜브 미디어 수집 워크플로우 통합).

소스 실측(spike run 31238546959): Google News 비즈니스 토픽 RSS(`hl=ko&gl=KR&ceid=KR:ko`)는
GitHub Actions 러너(해외 IP)에서도 접근 가능하며 한국어 한국판 랭킹 기사 70건을 반환.
`<source>` 태그(출처명)·`pubDate`(GMT) 포함.

## 요구사항

- **R1 (표시 위치·수량)**: 홈 소개 문단과 지표 테이블 사이에 "주요 뉴스" 블록을 표시해야
  하며, 항상 최신 헤드라인 **정확히 5건**(수집분이 5건 미만이면 있는 만큼)을 보여야 한다.
- **R2 (행 구성)**: 각 행은 시각 + 출처명 + 제목 링크로 구성해야 한다.
  - 시각: pubDate를 KST로 변환, 오늘이면 `HH:MM`, 오늘이 아니면 `MM.DD HH:MM`.
  - 출처명: RSS `<source>` 태그 값(예: 연합뉴스TV·한국경제). 외부 파비콘 이미지는 쓰지
    않는다(외부 의존·로딩 실패 리스크 — 참고 예시의 아이콘은 텍스트 출처명으로 대체).
  - 제목: 말미의 " - 출처명" 접미사를 제거한 순수 제목. 클릭 시 새 탭으로 원문 이동
    (`rel="noopener noreferrer"`).
- **R3 (수집)**: WHEN 매시간 미디어 수집 워크플로우가 돌면 THEN 시스템은 Google News
  비즈니스 토픽 RSS 상위 5건을 `data/news.json`으로 저장해야 한다. WHEN 수집·검증에
  실패하면 THEN 기존 news.json을 유지하고 워크플로우를 실패시키지 않아야 한다
  (유튜브 수집과 동일 정책).
- **R4 (프런트 갱신·회복력)**: 홈은 news.json을 summary와 동일한 주기(5분)로 폴링해야 한다.
  WHEN news.json이 없거나 로드에 실패하면 THEN 뉴스 블록을 렌더하지 않아야 하며 지표
  테이블 표시에는 영향이 없어야 한다.
- **R5 (신선도)**: 뉴스 블록에는 별도의 "갱신 시각" 표기를 두지 않는다 — 행별 발행 시각이
  신선도를 전달한다. 단 WHEN 수집이 장기 실패해 news.json의 generated_at이 24시간을
  초과하면 THEN 블록을 숨겨야 한다(며칠 지난 기사가 "주요 뉴스"로 계속 노출되는 것 방지 —
  2026-08-08 적대적 검증 반영). 파이프라인도 같은 조건에서 `::warning`을 남긴다.
- **R6 (데이터 권리)**: `docs/data-rights.md`에 Google News RSS 행을 추가해야 한다.
  피드 저작권 고지가 "개인 피드리더 내 비상업 이용"을 명시하므로, 헤드라인+원문 링크
  표시(전문 미수록)는 관행 범위이나 **대중 공유 게이트 항목(⚠️)** 으로 기록한다.

## 비요구사항 (하지 않음)

- 기사 본문·요약 수록, 썸네일, 카테고리 필터, 뉴스 검색 — 헤드라인 5줄만.
- 프런트에서 RSS 직접 fetch — CORS·차단 리스크. 수집은 파이프라인 전용.

## 검증 계획

- pytest: RSS 파싱(제목 접미사 제거·출처·시각 변환·5건 절단), 실패 시 기존 파일 유지.
- vitest: 시각 포맷(KST·오늘/이전), 블록 렌더·실패 시 숨김.
- 러너 실수집(workflow_dispatch) 후 배포 사이트 실측.
