# Requirements — chart-usability

상세 모달 차트의 조작성·가독성 개선: 휠 줌·팬으로 자유로운 기간 탐색, 라인 지표 MA 토글(기본 꺼짐), 수급 누적 모드 (2026-08-08 사용자 요청).

## 배경과 목적

현재 상세 차트는 기간 버튼(3M~5Y)이 **데이터 자체를 잘라내고 차트를 재생성**하는 구조라, 버튼 5개 외 기간은 볼 수 없고 옵션을 바꿀 때마다 보던 위치가 리셋된다. 사용자 요청: "여러 기간을 조절해서 볼 수 있으면 좋겠다(마우스 중간 스크롤로 기간 조절 등)" — 개인 전문투자자 눈높이의 표준 차트 조작(줌·팬)은 갖추되 고급 기능(그리기 도구·비교 오버레이 등)은 넣지 않는다. 참고 예시: 메르 유튜브의 "외인순매수(주) 누적 + 4주 이동평균" 차트.

인터뷰 결정(2026-08-08):

- 수급 상세에 **누적 전환** 추가 — 예시 이미지의 "외인순매수 누적" 관점 재현
- 라인 지표(환율·국채·WTI·VKOSPI·신규 해외 라인 지표)에 **MA 토글 재도입, 기본 꺼짐** — 8/3의 "라인 지표 MA 제외" 결정을 옵트인 방식으로 완화

## 요구사항

- R1. WHEN 상세 화면이 열리면 THEN 시스템은 전체 시계열(약 5년)을 차트에 로드하고 기본 보기 범위를 최근 1년으로 설정해야 한다. WHEN 기간 버튼(3M/6M/1Y/3Y/5Y)을 클릭하면 THEN 데이터 재로드·차트 재생성 없이 보이는 시간 범위만 전환해야 한다.
- R2. WHEN 차트 위에서 마우스 휠을 굴리면 THEN 시간축이 커서 위치 기준으로 줌인/줌아웃되어야 하고, 드래그로 좌우 팬, 터치 기기에서는 핀치 줌·수평 스와이프 팬이 되어야 한다(수직 스와이프는 페이지 스크롤 유지). 차트 위 휠이 페이지 스크롤 대신 줌으로 소비되는 것은 금융 차트 관례로 수용한다.
- R3. WHEN MA 체크박스·수급 집계 모드 등 옵션을 바꾸면 THEN 현재 보고 있는 시간 범위가 유지되어야 한다(현재는 전체 재생성으로 1Y로 리셋됨). 테마 전환 시에도 동일하다. 단 일별↔주간처럼 바 단위가 바뀌는 전환에서는 스냅으로 인한 ±1주 미만 오차를 허용하되, 우측 끝(최신 데이터)을 보고 있었다면 전환 후에도 우측 끝이 보여야 한다.
- R4. 라인 지표 상세에 MA 20/60/120일 체크박스를 제공하되 기본은 모두 꺼진 상태여야 한다. 캔들 지표는 현행(기본 켜짐) 유지. MA 색상은 기존 `--ma-1..3` 규칙을 따른다.
- R5. 수급(flows) 상세의 집계 전환을 일별/주간/**누적** 3모드로 확장한다. 누적 모드는:
  - 로드된 시계열 시작점(약 5년 전)을 0으로 하는 주체별 누적 순매수 라인을 그린다
  - 기본 표시는 **외국인 단독**, 개인·기관은 체크박스로 추가(예시 차트의 초점이 외국인 자금 이탈·유입이므로)
  - **4주(20영업일) 이동평균** 오버레이를 제공한다(기본 켜짐, 표시 중인 주체에 각각 적용)
  - 범례 행 우측에 요약을 표시한다: 표시 주체의 누적 합계·오늘 순매수·직전일 순매수(예시 이미지의 "누적/오늘/직전일" 박스 관점, 억원→조원 자동 환산은 기존 포맷 규칙). 차트 위 오버레이가 아니라 범례 행에 두어 크로스헤어 툴팁과의 겹침을 피한다
- R6. 상세 헤더의 현재값 옆에 전일 대비 등락을 표시한다(일반 지표 ±%, 수급 ±억원) — 전역 색 규칙(+빨강/−파랑/보합 회색).
- R7. 기존 동작 회귀 없음: 크로스헤어 툴팁, 거래량 서브패널(삼성전자·SK하이닉스), 캔들 MA 워밍업(표시 구간 앞 데이터로 계산), 라이트/다크 테마.

## 검증 계획

- vitest: 누적 시계열 계산·요약 박스 값 도출 등 순수 함수 단위 테스트, 기존 회귀 전체
- 브라우저 실측: 휠 줌·드래그 팬·기간 버튼 점프, 옵션 변경 시 범위 유지, 수급 누적 모드(주체 토글·4주 MA·요약 박스), 모바일 뷰포트(핀치·세로 스크롤 공존), 라이트/다크
- `tsc -b && vite build` 성공

## 범위 제외 (백로그)

- 그리기 도구, 지표 간 비교 오버레이, 로그 스케일, 보조지표(RSI 등) — "너무 고급 기능은 넣지 않은 형태" 지시에 따라 제외
- 수급 누적의 임의 기준일 지정(특정 날짜부터 누적) — 줌으로 구간을 좁혀 보는 것으로 갈음
- 홈 스파크라인 변경 없음(요청 범위 밖)
